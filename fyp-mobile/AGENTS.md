# Booking user guides

When changing actions, labels, deadlines or outcomes on client My Events, vendor My Events or vendor Order Summary, review `components/guides/bookingGuideContent.ts` in the same change and update affected steps. Keep the guide consistent with what the app currently does. Use short, simple English for clients and vendors; do not explain internal implementation or temporary Admin payment steps. Reuse `BookingUserGuide` for these screens instead of creating duplicate guides.
